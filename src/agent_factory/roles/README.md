Built-in roles start from the execution packet and write only its report_path
(plan §5.3, §7.2, §8.2). Each role has one provider-neutral source; worktree,
skills and permission instructions cover both providers without duplicate files.
The original v1 role sources were removed in session 4.3 after these package roles replaced them.

Tests check every role file, report sections, contracts and provider resolution.

The rewrite preserves substantive review and escalation checks. Legacy output,
tools/model metadata, generated-file notices, job.json traversal, whole-history
reads and fixed browser session names were removed in favor of packet paths,
current evidence and browser_session. Packet summaries include recorded heads
so approval can retain its review-head check without legacy history. Builder
Summary/Validation/Log content is carried by Changes/Checks run/Decisions;
spec Pages becomes Pages to check,
review Checked becomes Checks run, and approval Why becomes Reasons. Historical
log copying is replaced with relevant decisions and finding responses from the
packet. Provider variants were consolidated because no distinct wording remains
necessary. No substantive check was deliberately removed.
